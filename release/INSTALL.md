# twtdash — install in 60 seconds

## Chrome · Edge · Brave · Arc · Opera

1. Open `chrome://extensions` (Edge: `edge://extensions`, Brave: `brave://extensions`).
2. Turn on **Developer mode** (top-right toggle).
3. Click **Load unpacked** and select the folder **`twtdash-extension`** (next to this file).
4. Click the puzzle icon in the toolbar → pin **twtdash**.
5. Make sure you're logged in to **x.com** in this browser, then click the twtdash icon → **Sync my bookmarks**.
   Keep the X tab that opens visible while it scrolls (about a minute per 1,000 bookmarks).

Your dashboard opens automatically after install. Shortcut: **Alt + Shift + S** opens it from anywhere.
Want to look around first? Click **Explore with sample data** on the welcome screen.

## Firefox (128+)

1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on…** and pick any file inside `twtdash-firefox.zip` after unzipping it (e.g. `manifest.json`).
   (Temporary add-ons are removed when Firefox restarts — for a permanent install, publish the zip on addons.mozilla.org.)

## Files

| File | What it is |
|---|---|
| `twtdash-extension/` | Ready-to-load Chrome/Edge/Brave build |
| `twtdash-chrome.zip` | Same build, zipped — upload this to the Chrome Web Store |
| `twtdash-firefox.zip` | Firefox build — upload to addons.mozilla.org |

Everything is stored locally in your browser. Nothing is sent anywhere unless you turn on AI in Settings.
